# Precise Player

A frame-accurate video player for Android, powered by mpv. Smooth scrubbing, frame stepping,
millisecond-precise seeking and volume. No ads, no tracking. GPL-3.0.

**Download:** [latest APK](https://github.com/jaydabnknt/precise-player/releases/latest/download/PrecisePlayer.apk)

- Built entirely by GitHub Actions: `Build engine` (libmpv/FFmpeg, run rarely) and `Build app` (every push).
- Publishing: see [PLAY_STORE.md](PLAY_STORE.md). Privacy: [PRIVACY.md](PRIVACY.md).
- Developer notes: [CLAUDE.md](CLAUDE.md), [PROGRESS.md](PROGRESS.md).
